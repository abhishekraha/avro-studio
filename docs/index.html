Capabilities

Everything required for mission-critical schema migrations

Built to eliminate breaking changes, manual JSON/IDL editing errors, and untracked downstream data pipeline drifts.

Dual-Pane Visual Restructurer

Side-by-side editing pane with immutable source contract on the left and dynamic editable draft on the right. Live SVG cubic bezier connecting lines trace every field and lineage.

Cross-Record Restructuring

Move fields across separate records (e.g. from Order into new normalized OrderSummary or Shipment records). Visual bezier lines highlight and track lineage.

Multi-Contract Workspaces

Manage multiple interrelated schema contracts in tabbed sessions. Add, duplicate, rename, or switch contracts instantly while maintaining workspace state.

SemVer Bumping & Namespaces

One-click semantic version bumps (+Patch, +Minor, +Major) with dedicated namespace isolation per record to avoid naming collisions across microservices.

BigQuery & AVDL Serialization

Generate production-ready BigQuery JSON schemas and standard Avro IDL. Full support for nested RECORD modes, REPEATED arrays, nullable fields, and logical types (timestamp-millis, decimal).

Tabular Data Reconciliation

Automated reconciliation engine executing key-based comparisons between source and target datasets using schema linkages, computing match percentages and mismatch details.

Specialized Migration Capability

Seamless Cross-Record Field Movement & Linkage

In modern event-driven architectures, domain refactoring often requires splitting monolithic records into normalized entities—for example, moving customer credentials and shipping addresses from an Order record into an OrderSummary or Shipment event.

  • Manual or Drag-and-Drop Reparenting

    Re-link source fields to any target record or drop fields into new records with automatic ID tracking.

  • Glowing Connection Overlays

    SVG cubic bezier overlays adapt to viewport resizing and scrolling, highlighting cross-record links with luminous neon gradients.

  • Automated Migration Spec Export

    Export linkages as structured JSON artifacts for automated ingestion by Spark, Flink, or dbt ETL migration pipelines.

Linkages JSON Export Sample linkages.json

  "schemaVersion": "2.1.0",

Architecture

Single-Port Architecture & High-Throughput Core

Lightweight Hono backend, better-sqlite3 with WAL mode, and modular AST serialization pipelines.

Client Layer

React 19 SPA built with Vite and Tailwind CSS. Features customized @dnd-kit integration for drag-and-drop field reordering, real-time SVG bezier path calculation, and per-user identity tracking.

  • • Responsive dual-pane viewport
  • • Live syntax-highlighted IDL preview
  • • Dynamic modal stack with Esc listener

Server & Proxy Layer

Unified Hono server hosting REST APIs and serving client bundle on port 3000. Includes built-in CORS bypass proxy for Confluent / Karapace Schema Registry endpoints.

  • • /api/workspaces persistence
  • • /api/registry/* proxy endpoints
  • • Static asset serving with fallback routing

Storage & Engine Layer

Embedded SQLite storage managed via better-sqlite3 running in write-ahead logging (WAL) mode for multi-session data persistence with sub-millisecond query performance.

  • • Multi-contract schema version snapshots
  • • Key-based tabular data reconciliation engine
  • • BigQuery type translation AST pipeline

API Endpoints & Contract Formats

REST API Routes

List all persisted workspaces, metadata, and active contracts.

POST /api/workspaces

Save or update workspace payload with multi-contract protocols.

POST /api/registry/proxy

Proxy schema queries to external Confluent/Karapace Schema Registries.

GET /health

Liveness/readiness probe reporting database connectivity.

Supported Schema Specifications

Apache Avro IDL (.avdl)

Full support for @namespace, protocols, nested records, enums, fixed, arrays, maps, and unions.

Avro JSON Schema (.avsc)

Bi-directional conversion between standard Avro JSON schema declarations and IDL protocols.

Google BigQuery Table Schema

Translates Avro schema trees into BigQuery field arrays with RECORD nested modes and documentation pass-through.

Migration Linkages Spec (.json)

Machine-readable migration dictionary capturing identical, renamed, added, deleted, and cross-record moved fields.

Deployment

Docker & Quickstart

Docker Run (Recommended) 

# Build Docker image
docker build -t avro-studio:latest .

# Run container with persistent SQLite volume on port 3000
docker run -d -p 3000:3000 -v avro-data:/data --name avro-studio avro-studio:latest

# Open in browser: http://localhost:3000

Local Development Setup 

# Clone and install dependencies
git clone https://github.com/abhishekraha/avro-studio.git
cd avro-studio
npm install

# Run Vitest test suite (140+ unit, integration & e2e tests)
npm test

# Build client and server bundles
npm run build

# Start production server
npm start
